                      TROUBLESHOOTING

IF BUILD FAILS:

1. Try clean build:
   .\gradlew clean
   .\gradlew assembleRelease

2. Update dependencies:
   cd ..
   npm install --legacy-peer-deps
   cd android
   .\gradlew assembleRelease

3. If CMake/native errors occur:
   This is a known issue with react-native-mmkv
   Try:
   .\gradlew assembleRelease --no-build-cache

4. Check Java version:
   java -version
   (Should be 17+)
